# Portfolio_ni_gerald# Gerald Villar | MLBB 10th Anniversary Portfolio

A responsive **Mobile Legends: Bang Bang (MLBB) Hero Skins Portfolio** website created as a gaming-themed personal portfolio for **Gerald Villar**.

## 📌 Project Overview

This project presents an interactive MLBB-inspired portfolio featuring:

- A 10th Anniversary themed homepage
- About section for Gerald Villar
- Hero skin collection
- Hero search functionality
- Hero role filters
- Clickable hero cards with modal information
- Responsive navigation menu
- Animated visual effects
- Mobile-friendly responsive layout
- Contact section and footer

The website is contained in a single HTML file with CSS and JavaScript included directly in the document.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Layout, colors, animations, responsive design, and visual effects
- **JavaScript** — Navigation menu, hero filtering, search, and modal interactions
- **External image URLs** — Images displayed in the hero skin cards

## ▶️ How to Run

1. Download or copy the project files.
2. Keep `geraldvillar.html` in its original `.html` format.
3. Double-click `geraldvillar.html`, or right-click it and open it with a web browser.
4. Use the navigation menu to explore the different sections.

No server or installation is required for the basic version.

## 🧭 Website Navigation

The navigation bar contains:

- **Home** — Opens the main MLBB portfolio introduction.
- **About** — Displays information about Gerald Villar and portfolio statistics.
- **Hero Skins** — Opens the hero skin collection.
- **10th Anniversary** — Displays the anniversary section.
- **Contact** — Opens the contact section.

On smaller screens, the navigation changes to a menu button.

## 📱 Responsive Design

The website includes responsive CSS for smaller screens. On devices with a screen width of 768px or less:

- The desktop navigation is replaced by a menu button.
- The navigation links become a vertical menu.
- The hero heading becomes smaller.
- The About section changes to a single-column layout.

## 📸 Images

The current HTML references external image URLs for the hero cards. An internet connection may therefore be required for those images to load correctly.

## ⚙️ JavaScript Features

The JavaScript provides the following functions:

- `toggleMenu()` — Opens and closes the mobile navigation menu.
- `filterHeroes(category)` — Filters hero cards by role.
- `searchHeroes()` — Searches hero cards by hero name.
- `openModal(name, description, image)` — Opens the hero information modal.
- `closeModal()` — Closes the modal.
- `window.onclick` — Allows the modal to close when the user clicks outside it.
